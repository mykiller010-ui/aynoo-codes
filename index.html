01Give codes and _C names

Copy a give code, open the console in game with Tab, paste with Ctrl+V and press Enter. The _C name is what server settings and shops ask for.

02Use the codes in game

Give an item to yourself

  1. On your server, log in as admin once per session: press Tab, then type EnableCheats, a space, and your admin password, then press Enter. In single player you can skip this.
  2. Copy the item's give code from the list above. Set Amount first if you want more than one.
  3. In game press Tab, paste with Ctrl+V, press Enter. The item lands in your inventory.

Give an item to another player

  1. Press Esc and click ADMIN (or the ADMIN button under your inventory). Only admins see it.
  2. Pick the player in the list.
  3. Use GIVE COINS with an amount, or pick an item and press GIVE. The list there has 35 items: the cosmetics, the streamer jackets, the AYNOO Vault, the Vault Controller and the storage boxes. Loot drops have their own buttons.

Streamer jackets (Game Series, SAS, WAEL51) have no engram. Players can only get them from you, by code or from the admin panel.

What the numbers at the end mean

cheat GiveItem "…" 1 0 0 = amount, quality, blueprint. Change the first number for more items. Set the last one to 1 to give a blueprint instead of the item (the Blueprint box above does it).

03Server settings

Load the mod on your server

  1. Add -mods=1719367 to the server start line. With other mods, separate the IDs with commas and no spaces: -mods=1719367,111111.
  2. On a hosting panel, put 1719367 in its Mods field instead.
  3. Restart the server. It downloads the newest approved version by itself; players get it when they join.

AYNOO settings (GameUserSettings.ini)

Switch AYNOO features on or off and change their main numbers, without a mod update.

  1. Stop the server. ARK rewrites GameUserSettings.ini when it shuts down, so changes made while it runs are lost.
  2. Copy the block below and paste it at the end of the server's GameUserSettings.ini (the same file as [ServerSettings]).
  3. Change the lines you want, then start the server.
[AynooMod]
; AYNOO Vault: Slots of every AYNOO Vault. Allowed: 1 to 1000. Default: 1000

AutoPull=True
; AYNOO Vault Controller: Highest range in metres players can set; placed controllers above it are lowered to it. Allowed: 5 to 100. Default: 50
ControllerMaxRange=50
; AYNOO Vault Controller: Starting range in metres of a newly placed Vault Controller. Allowed: 5 to ControllerMaxRange. Default: 20
ControllerRange=20
; AYNOO Vault Controller: Seconds a Vault Controller waits between two deposits (Deposit now and the auto-pull when a vault is opened). Allowed: 0 to 60. Default: 2.0
DepositCooldown=2.0
; Keeper: True = a player gets their Aynoo Coins back after respawning. False = at death the coins drop in a loot bag next to the body, and anyone can pick it up. Allowed: True/False. Default: True
KeepCoinsOnDeath=True
; Keeper: True = AYNOO cosmetics in the bag come back after respawning. False = at death they drop in a loot bag next to the body, and anyone can pick it up. Worn cosmetics always stay with the player. Allowed: True/False. Default: True

ArenaSpectatorProtection=True

EscMenu=True
; ESC menu: Name shown at the top of the ESC overlay and on its left panel. Allowed: text, up to 40 characters. Default: AYNOO.NET
ServerName=AYNOO.NET
; ESC menu: Discord button + QR. Allowed: True/False. Default: True
ShowDiscord=True
; ESC menu: Store button + QR. Allowed: True/False. Default: True
ShowStore=True
; ESC menu: Website button. Allowed: True/False. Default: True
ShowWebsite=True

Every value in the block is the default, so pasting it changes nothing until you edit a line. A missing line, or no [AynooMod] section at all, keeps the default. A wrong value (text where a number belongs, or out of range) uses the default or the nearest allowed value. The server reads the values once when it starts.

Change engrams, recipes and stacks (Game.ini)

These lines go in Game.ini under [/script/shootergame.shootergamemode]. They use the short _C names from the list. Restart the server after a change. Examples:

AYNOO Vault engram (default level 35, 18 points):

OverrideNamedEngramEntries=(EngramClassName="EngramEntry_AynooVault_C",EngramLevelRequirement=35,EngramPointsCost=18,EngramHidden=False)

AYNOO Vault recipe (default 60 metal ingot, 25 crystal, 40 cementing paste, 15 polymer):

ConfigOverrideItemCraftingCosts=(ItemClassString="PrimalItemStructure_AynooVault_C",BaseCraftingResourceRequirements=((ResourceItemTypeString="PrimalItemResource_MetalIngot_C",BaseResourceRequirement=60,bCraftingRequireExactResourceType=false),(ResourceItemTypeString="PrimalItemResource_Crystal_C",BaseResourceRequirement=25,bCraftingRequireExactResourceType=false),(ResourceItemTypeString="PrimalItemResource_ChitinPaste_C",BaseResourceRequirement=40,bCraftingRequireExactResourceType=false),(ResourceItemTypeString="PrimalItemResource_Polymer_C",BaseResourceRequirement=15,bCraftingRequireExactResourceType=false)))

Hide an engram (example: the Glow Totem), so nobody can learn it:

OverrideNamedEngramEntries=(EngramClassName="EngramEntry_AynooGlowTotem_C",EngramHidden=true)

Aynoo Coin stack size (default 1000):

ConfigOverrideItemMaxQuantity=(ItemClassString="PrimalItemConsumable_AynooCoin_C",Quantity=(MaxItemQuantity=1000,bIgnoreMultiplier=true))
