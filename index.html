01Give codes and _C names

Copy a give code, open the console in game with Tab, paste with Ctrl+V and press Enter. The _C name is what server settings and shops ask for.

02Use the codes in game

Give an item to yourself

  1. On your server, log in as admin once per session: press Tab, then type EnableCheats, a space, and your admin password, then press Enter. In single player you can skip this.
  2. Copy the item's give code from the list above. Set Amount first if you want more than one.
  3. In game press Tab, paste with Ctrl+V, press Enter. The item lands in your inventory.

Give an item to another player

  1. Press Esc and click ADMIN (or the ADMIN button under your inventory). Only admins see it.
  2. Pick the player in the list.
  3. Use GIVE COINS with an amount, or pick an item and press GIVE. The list there has 34 items: the cosmetics, the streamer jackets and the Auto Deposit. Loot drops have their own buttons.

Streamer jackets (Game Series, SAS, WAEL51) have no engram. Players can only get them from you, by code or from the admin panel.

What the numbers at the end mean

cheat GiveItem "…" 1 0 0 = amount, quality, blueprint. Change the first number for more items. Set the last one to 1 to give a blueprint instead of the item (the Blueprint box above does it).

03Server settings

Load the mod on your server

  1. Add -mods=1719367 to the server start line. With other mods, separate the IDs with commas and no spaces: -mods=1719367,111111.
  2. On a hosting panel, put 1719367 in its Mods field instead.
  3. Restart the server. It downloads the newest approved version by itself; players get it when they join.

Change engrams, recipes and stacks (Game.ini)

These lines go in Game.ini under [/script/shootergame.shootergamemode]. They use the short _C names from the list. Restart the server after a change. Examples:

Auto Deposit engram (default level 35, 18 points):

OverrideNamedEngramEntries=(EngramClassName="EngramEntry_AynooDeposit_C",EngramHidden=false,EngramPointsCost=18,EngramLevelRequirement=35,RemoveEngramPreReq=false)

Auto Deposit recipe (default 60 metal ingot, 25 crystal, 40 cementing paste, 15 polymer):

ConfigOverrideItemCraftingCosts=(ItemClassString="PrimalItemStructure_AynooDeposit_C",BaseCraftingResourceRequirements=((ResourceItemTypeString="PrimalItemResource_MetalIngot_C",BaseResourceRequirement=60.0,bCraftingRequireExactResourceType=false),(ResourceItemTypeString="PrimalItemResource_Crystal_C",BaseResourceRequirement=25.0,bCraftingRequireExactResourceType=false),(ResourceItemTypeString="PrimalItemResource_ChitinPaste_C",BaseResourceRequirement=40.0,bCraftingRequireExactResourceType=false),(ResourceItemTypeString="PrimalItemResource_Polymer_C",BaseResourceRequirement=15.0,bCraftingRequireExactResourceType=false)))

Hide an engram (example: the Glow Totem), so nobody can learn it:

OverrideNamedEngramEntries=(EngramClassName="EngramEntry_AynooGlowTotem_C",EngramHidden=true)

Aynoo Coin stack size (default 1000):

ConfigOverrideItemMaxQuantity=(ItemClassString="PrimalItemConsumable_AynooCoin_C",Quantity=(MaxItemQuantity=1000,bIgnoreMultiplier=true))

These are ARK's standard Game.ini settings. After a server restart, check one change in game before you rely on it.

Shops and plugins

Most shop plugins want the Blueprint path: the part inside the quotes of a give code, for example

Blueprint'/AynooMod/Deposit/PrimalItemStructure_AynooDeposit.PrimalItemStructure_AynooDeposit'

If a tool asks for a class name instead, use the _C name (short) or the full _C path (open "All class paths" on an item).

Send an AYNOO notification

Call ClientAynooNotify(Type, Title, Message, Duration) on the server, on that player's PrimalBuff_AynooNotify_C. It shows on that player's screen.

Types: info, success, warning, error, reward, pvp, safezone, announcement, shop. Duration 0 uses the type's default. Not tested with a real plugin yet.
